# data/market_logos/ — 마켓 IG 프로필 아바타

이 디렉터리의 이미지는 **각 마켓 본인의 인스타그램 프로필 사진**이며, 우리가 만든 것이 아니다.
저장 근거와 경계는 [ADR-0010](../../docs/adr/0010-market-logo-assets.md) 에 있다 —
ADR-0009 §1 의 "다운로드·재호스팅 배제"를 **식별 표지에 한해** 한정한 결정이다.

- 마켓당 **1개**, 320px(`profilePicUrlHD`), 그 마켓 본인 계정에서만.
- 화면에 그릴 때는 **항상** `instagram.com/{handle}` 링크를 같이 그린다(예외의 조건).
- 게시물 사진·유저 후기 미디어는 여전히 전면 금지(ADR-0009 §4 무변경).

## 내려달라는 요청이 오면

**해당 `.jpg` 파일을 지우면 끝난다.** KB 도 코드도 건드릴 필요 없다 —
`source_links.logo_asset()` 이 파일 부재를 확인하고 모노그램 칩으로 자동 degrade한다.
철회 비용이 낮다는 사실이 ADR-0010 의 전제이므로, 이 성질을 없애는 변경(예: 파일을 못 찾으면
KB 경로를 그대로 렌더)은 그 결정의 근거를 무너뜨린다.

## 채우기

```bash
python -m slime_rag.logos --dry-run   # 대상·비용만
python -m slime_rag.logos             # Apify 프로필 액터 1회 실행(과금) + 다운로드
```
