# ADR-0002 — 소스 편향을 1급 기능으로 (평균 금지)

**상태:** Accepted

## 맥락
인스타 캡션은 긍정 쏠림, 디시 아모스갤은 부정 쏠림. 두 소스를 평균내면 실제 신호가 사라진다.

## 결정
소스 편향은 보정 대상이 아니라 **드러낼 기능**. 정서를 **소스별 + 소스 간 갭**으로 제시하고,
절대 평균내지 않는다.

## 근거
- **Why:** "봄 제품 좋아?"에 4.1/5 같은 평균은 거짓 확실성. "인스타 긍정 / 디시 혼재, 갭 큼"이
  사용자에게 훨씬 정직하고 유용.
- 보정(정규화)보다 **라벨링**을 택한다 — 편향의 출처를 투명하게.

## 영향
- `slime_rag/consolidated_view.py` 가 소스별 정서·갭·향불일치·소스aware 요약 산출.
- `reviews.source` 가 편향 집계 키. 홍보성은 추가로 `review_class` 로 분리([ADR-0004](0004-promo-gate-llm-cascade.md)).
